# Legend contact feedback: native visual review

Godot 4.5.1, Vulkan Forward+, NVIDIA GeForce RTX 5080. The real `main.tscn`, twelve native avatars and the actual career adapter were used. User data was isolated under `.runtime/legend75-feedback-render`; no personal career profile was read or changed.

`tools/Capture-LegendFeedback75.gd` completed **114 checks with no failures** and saved **18 native screenshots**: forearm readiness and result, overhead readiness and result, explicit RT dive, and the English help screen at 1280×720, 1920×1080 and 2560×1440. The overhead contact advances the existing ballistic flight through the real shared match step. Device-label checks cover keyboard, PlayStation and Xbox buttons.

The read-only cue was called repeatedly while checking the ball position and velocity, all twelve player roots, RNG state, input quality and the armed flag. All remained unchanged.

The contact panel occupies `(660,810,600,140)` in the 1920×1080 layout. It ends 16 pixels above the shared power panel, between the athlete and control cards, and below the shared timing result and scoreboard. The reviewed 720p, 1080p and 1440p images show readable text without clipping or overlapping these panels. The overhead result shows the native hands above the head and the shared `PALLEGGIO` result. Bagher, overhead pass and dive have separate gesture labels; a prepared or buffered dive is identified as a request, without claiming a completed contact.

The English help screen originally exposed partial translations from the global fragment translator. Legend localization now prefers the complete en72/en75 sentence before falling back to the global translator. The final captures show complete English descriptions and button labels.

The automated report is `legend75-feedback-visual.json`. Screenshots use the prefix `legend75-feedback-`. Existing engine warnings about the root certificate store and loading image resources were also present; no GDScript error occurred in the successful run.
